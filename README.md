# Torus in ASCII characters

## **Compilation**
To compile, run the following command with gcc :

```gcc ascii_renderer.c -o [out_file_name] -lm && ./[out_file_name]```

It should render directly in the terminal. **To stop it enter Ctrl+C**.

## Notes

The file also contains an option to render a cube instead of a torus. More generally it displays any points cloud written in the ```verticesArray```.
